# Learning notes

Notes for each subject in the Study map dashboard. Every lesson has its own folder with a `README.md` to fill in.

Open `dashboard.html` in a browser to track progress; its notes links point at the folders here.

**Saving progress:** open the dashboard in Chrome or Edge, go to Settings → *Create save file…* and save it as `study-map.json` in this folder. Every change is then written to that file automatically. After reopening the dashboard, click *Reconnect study-map.json* in the header if the browser asks (choose "Allow on every visit" to skip this next time).
