# Clothes Care Rack — Brainstorming

## Notes

## Problems to Address

- Jeans start to smell after a couple of wears
- Annoying to hang up clothes (especially on getting in bed)
- Hard to keep track of how many times sweaters, etc have been worn

## Nice-to-Haves

- "Signature Smell" for clothes

## How to address problems

- Airflow - Timed fan for airflow when garment is hung up
- RFID tracking on hanger to track how many wears since last wash
- Vodka mister to handle bacteria growth
- Optional fragrance card slot in front of fan
- Clothespins instead of hangers - hang right from drying rack? (binder clips for more firm connection)
- Mini box to side, with removable grocery bags, for unders/socks/wash-right-aways
- Mesh laundry hamper on other side for time-to-wash (separated by colors/care type?)
- Hook on backside for hanging clothes post-dry, before transferring to closet (along with rack for folded items?)

## Requisite components

- Structure for hanging garments
- Structure on hanger for electronics
- Mount for fan (w/ slot for fragrance cartridge)
- Mount for mister
- RFID tracker
- Indicator for time-to-wash (leds? yellow for cleaning, red for time-to-wash, green for ready-to-hang?)
- Mini box for socks/unders
- Hamper for time-to-wash
- Rack for hanger-ready
- Rack for folding-ready
- Mister
- Mini box for clothespins
- Clothespins w/ electronics
- Arduino to control electronics (control indicators, fan control, mister control, rfid reader, memory for tracking)
